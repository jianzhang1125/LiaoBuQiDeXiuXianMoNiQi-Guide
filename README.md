# 了不起的修仙模拟器 · 纯正道攻略

[在线查阅](https://jianzhang1125.github.io/LiaoBuQiDeXiuXianMoNiQi-Guide/)

按阶段看流程，按问题查 Wiki。包含开局、结丹、守家、屠龙、长期培养，以及聚灵阵、功法、分神寄托、神修和地图资料。

## 阅读方式

- 12阶段先看目标、准备和小节目录，再按需展开细节。
- 流程术语直达 Wiki；目录、手机条目选择器、搜索和关联链接帮助来回查阅。
- 收藏、最近查阅与笔记存在当前浏览器；换设备时笔记可导出/导入。没有强制勾选或完成率。
- 原帖正文、完整截图、补充Excel与路线/版本说明保留。网页图使用原分辨率WebP质量92；本地原文件未修改。
- 聚灵阵提供中期水木、土金与屠龙后升级施工示意；自制四剑阵附四剑字／七剑字原图、六边格位置图与变阵截图。规则推导图均标明来源与适用人物。
- 正文使用本地图片与SVG流程图；视频链接折叠为可选出处，阅读无需打开视频。

## 发布和更新

本仓库是可直接部署的静态网站。GitHub Pages发布源为 `main` 分支根目录，`.nojekyll`关闭Jekyll处理。
在原始本地整理工程中依次运行 `python guide-work/build.py`、`python guide-work/check_reading_guide.py`、`python guide-work/export_github_site.py`，再提交导出的站点目录。本仓库保存的是可直接部署的导出站点，也可以直接维护其中的HTML/CSS/JavaScript。
发布包仅含网站和附带资料，不包含浏览器私人笔记、测试进度、缓存或下载的视频。
